tlsoverridefirefox
==================

This was an experiment long ago in converting DANE-EE records into the format of Firefox's `cert_override.txt`. It never worked particularly well, and Namecoin abandoned the approach pretty quickly. For a modern spin on the high-level goal, check out [ncp11](https://github.com/namecoin/ncp11).

This library is unmaintained, and is published because it's prime material for a "failed prototype museum", not because we expect you to use it. Perhaps it will inspire you to share your own failed prototypes.
